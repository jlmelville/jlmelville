Where did the density go?

I gave UMAP two groups of 5,000 points. In 50 dimensions the blue group has ten times the standard deviation of the orange one. How much of that difference makes it onto the page? Try changing the density scale in LEOPOLD, my approximation to densMAP in uwot.

Software

Run UMAP in R
uwot fits embeddings, works with labels and projects new observations into an existing embedding.
Find nearest neighbors
rnndescent works with dense and sparse data. RcppHNSW brings hnswlib to R. Both can supply neighbors to uwot.
Compare embeddings
I use smallvis to change one thing at a time in R. For larger 2D embeddings, its C++ code can approximate the repulsive forces with FFT interpolation, a Barnes–Hut tree or a mutual tree. In Python I use drnb to compare methods on the same datasets.
Optimize an objective
mize implements unconstrained optimizers in R. Its sibling funconstrain gives me 35 test problems from Moré, Garbow and Hillstrom to try them on.
Check a package change
revdeprunner helps me plan what needs building. It uses r-lib’s revdepcheck to run the checks.
