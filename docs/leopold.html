How I measured the radii

For each group I measured the root mean square distance from a point to the group’s center. I divided the blue group’s radius by the orange group’s radius. I used all 5,000 points per group, in all 50 dimensions for the input and in both dimensions for the embeddings. This measures the overall size of a group. LEOPOLD adjusts local density, so matching the input ratio here is a useful check on this example.

These are eleven separate uwot fits of two simulated Gaussians, all with the same exact neighbors and random starting coordinates. I used seed 42, 30 neighbors, min_dist = 0.1, 700 epochs and a single optimizer thread. Scale zero runs ordinary UMAP.
